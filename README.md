# GeoAdhikar — MVP (WebGIS + Decision Support)

GeoAdhikar is a lightweight, static (Vite) demo that recommends government schemes for Indian City/Tribal areas using a deterministic, rule-based scoring engine on synthetic/collected demo data. It includes an interactive Leaflet map with basemap switcher (OSM + Esri World Imagery), a location selector (State → District → City/Tribal area), area profile (numbers only), key challenges, and a recommendation list with explainability. A PDF export button lets you download the selected area’s report (profile + recommendations + rule-level explanations).

Important: DEMO ONLY. Data is synthetic or collected for demonstration and is non-authoritative. Some distributions are patterned on public sources:
- Census of India: https://censusindia.gov.in/
- Jal Jeevan Mission: https://ejalshakti.gov.in/jjmreport/
- Forest Survey of India (ISFR): https://fsi.nic.in/
- Data Portal India: https://data.gov.in/

## Data files and format (public/data/)

- `blocks.json` — 57 records (one per requested City/Tribal area) with numeric fields only: population, area_sq_km, tribal_population_percent, forest_cover_percent, agri_land_percent, households_with_water, villages_odf_plus, fra_claims, plus `last_updated` (ISO date). No provenance strings are displayed in UI.
- `blocks.csv` — same table in CSV form (same columns and order).
- `schemes.json` — 6 scheme definitions with rules and optional scaling.
- `admin_boundaries_sample.geojson` — synthetic small polygons keyed by `properties.block_id` for map highlighting.

To replace with real data:
- Keep the same keys in `blocks.json`. Replace the numbers and update `last_updated`.
- If you add schemes, follow the rule schema used in `schemes.json`.
- If you have real boundaries, replace the GeoJSON ensuring `properties.block_id` matches `blocks.json`.

## Scoring engine (summary)

Implemented in `src/app.js` as `computeSchemeScore(profile, scheme)`:
- need with op `<`: raw = clamp((value - v) / (value - scaling.min), 0, 1)
- need with op `>=`: raw = clamp((v - value) / (scaling.max - value), 0, 1)
- modifier: raw = 1 if condition satisfied else 0
- eligibility: if fails → short-circuit (eligible=false, score=0)

Sum(weight * raw) across rules → score in [0,1], then ×100 for display. Each rule has a human-friendly explanation. Recommendations sorted by eligibility then score; top 5 shown.
